# Sistem-Intersectie-Semaforizata-Iluminata-cu-Alarma
Proiectul „Sistem Intersecție Semaforizată Iluminată cu Alarmă” constă în realizarea unui sistem automatizat destinat controlului circulației într-o intersecție rutieră. Acesta simulează funcționarea unui semafor real, utilizând semnale luminoase pentru dirijarea traficului auto și pietonal, prin alternarea culorilor roșu, galben și albastru..
