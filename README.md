# 🚦 Sistem Intersecție Semaforizată Iluminată cu Alarmă

Un proiect embedded/electronic care simulează o intersecție semaforizată inteligentă, iluminată și dotată cu sistem de alarmă pentru gestionarea traficului și creșterea siguranței rutiere.

---

## 📌 Descriere

Acest proiect reproduce funcționarea unei intersecții semaforizate utilizând LED-uri pentru semafoare, efecte de iluminare și un sistem de alarmă sonoră/luminoasă pentru situații speciale. Sistemul controlează automat ciclurile de trafic și poate simula scenarii reale de circulație urbană.

Proiectul este realizat în scop educațional și demonstrează concepte de:
- electronică digitală
- automatizări
- programare embedded
- logică secvențială
- control al traficului

---

## 🔌 Configurație pini Arduino

| Componentă                     | Pin Arduino |
| ------------------------------ | ----------- |
| LED Galben (Semafor Mașini)    | D12         |
| LED Roșu (Semafor Mașini)      | A4          |
| LED Albastru (Semafor Mașini)  | D3          |
| LED Albastru (Semafor Pietoni) | A5          |
| LED Roșu (Semafor Pietoni)     | D5          |
| LED Lumină 1                   | D8          |
| LED Lumină 2                   | D7          |
| Buzzer                         | D6          |
| Buton Pieton (8 secunde)       | A0          |
| Buton Pieton (3 secunde)       | A1          |
